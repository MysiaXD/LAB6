## 📝 Опис варіанту

1. **Розрахунок параметрів:**
   - C₂ = 5102 % 2 = 0 (Інтерфейс: `List`)
   - C₃ = 5102 % 3 = 2 (Внутрішня структура: Двозв'язний список)

2. **Тип колекції:** Типізована (Generic) колекція, що зберігає об'єкти класу `Ammunition` (та його нащадків `Armor`, `Weapon`, `Shield`) з лабораторної роботи №5.

3. **Реалізація структури даних:** Колекція побудована на базі двозв'язного списку, де кожен елемент (вузол) має посилання на наступний та попередній елементи. Колекція реалізує стандартні методи інтерфейсу списку (додавання, видалення, очищення, перевірка наявності тощо).

4. **Вимоги до конструкторів:**
   - Порожній конструктор для створення порожнього списку.
   - Конструктор, який приймає 1 об'єкт класу `Ammunition`.
   - Конструктор, який приймає стандартну колекцію об'єктів (наприклад, стандартний `list` у Python) для ініціалізації.
